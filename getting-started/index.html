Getting started

This is the starting point for merchants configuring ADLAC.

1. Install the theme

After installing ADLAC, open the Shopify theme editor and review the global Theme settings before editing individual templates.

2. Configure global styles

Set typography, colors, page width, corner radii, social links, and Quick Buy presentation from Theme settings.

3. Configure storefront features

Header & navigation

Logo, search, account controls, dropdowns, and mega menus.

Products

Media gallery, variants, specifications, tabs, reviews, and Quick Buy.

Collections

Collection headers, filters, sorting, product cards, swatches, and pagination.

4. Test before publishing

Test desktop and mobile layouts, keyboard navigation, product variants, cart actions, search, filters, localization, and installed app blocks.
