Localization

Markets & languages

Use ADLAC with Shopify languages, country/region context, currencies, and translated theme content.

ADLAC 1.0.0Shopify Online Store 2.0

Languages

ADLAC includes English and Romanian locale files in the supplied theme. The footer language selector appears when Shopify reports more than one available language.

Countries and currencies

The footer country selector appears when more than one country/region is available. Each option displays the country and its currency code and submits through Shopify's localization form.

Theme translations

Storefront strings and Theme Editor schema labels are stored separately in the theme's locale files. When adding or changing merchant-facing settings, keep the English and Romanian schema locale key structure synchronized.

Market-specific content

Use Shopify's market and localization features for country/language context rather than hard-coding country-specific URLs into the theme. Test navigation, prices, search, cart, and product content in each published market.
