Theme section

Product stage

Display featured product content in a visual stage layout with product details and media.

ADLAC 1.0.0Shopify Online Store 2.0
Where to configure this in ShopifyOpen Online Store → Themes → Customize, select a template where the section is available, then choose Product stage in the theme editor. ADLAC exposes the settings and blocks listed below. Availability depends on the selected template and the theme's section groups.

How to set it up

  1. Open the template or section group that uses this section.
  2. Choose the section and adjust its settings using the editor labels shown below.
  3. Add or reorder the compatible blocks listed below.
  4. Preview desktop and mobile, then save the theme.

Key settings

  • Show vendor
  • Show price
  • Show product specifications
  • Autoplay products
  • Change product every
  • Transition
  • Show navigation arrows
  • Show product tabs
