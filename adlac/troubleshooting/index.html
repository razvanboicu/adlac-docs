Help

Troubleshooting

Use these checks before changing code or contacting support.

ADLAC 1.0.0Shopify Online Store 2.0

Navigation block does not open

Confirm that the Mega menu or Compact dropdown block's Top-level menu item exactly matches the title of the corresponding top-level link in the selected Header menu.

Quick Buy loads the wrong product or variant

Confirm the product card links to the expected product and that variant option values/linked-product URLs are configured correctly. Test the full product page first to verify the underlying Shopify variant data.

Review widget is blank in an inactive tab

Keep the review widget as an app block inside the Reviews Information tab. ADLAC keeps inactive tab panels measurable and dispatches layout signals when tabs are shown, but some apps may still require their own refresh behavior.

Product specifications are missing

Check that the metafield definitions use the specs namespace and one of the supported keys, that the product has a value, and that the Product specifications block has not reached its Maximum specifications limit.

Collection/search filters are missing

Verify that Shopify has filters configured for the storefront and that the current collection/search context exposes them. ADLAC does not invent filter data.

Country or language selector is missing

The selector is only rendered when Shopify reports more than one available country or language.

Video autoplay does not start

Browser autoplay policies commonly require autoplaying video to be muted. In ADLAC media sections, use the section's Mute video setting when autoplay is enabled.

Theme Editor setting and documentation wording differ

Use the current theme version and report the mismatch. ADLAC documentation is intended to use the same merchant-facing names as the Theme Editor.
