ADLAC / Reviews & app blocks

Apps

Reviews & app blocks

Add product reviews and other app content using Shopify app blocks instead of provider-specific theme integrations.

ADLAC 1.0.0Shopify Online Store 2.0

Vendor-neutral architecture

ADLAC does not require a specific review provider to populate the Reviews tab. The product information architecture accepts Shopify app blocks inside an Information tab, so a compatible review app can render its own widget without editing theme code.

Add a review app to the Reviews tab

Install your review app

Install a Shopify review app that provides a theme app block for product reviews.

Open the product template

In the theme editor, open the default product template and select Main product → Product information tabs.

Open or add the Reviews tab

Select an Information tab and set Tab label to Reviews.

Add the app block

Inside that tab, choose Add block → Apps and select the review app's product review block.

Rating summary

The Information tab includes an optional Rating summary setting. Leave it hidden unless the installed app maintains Shopify's standard product rating metafields. When enabled, the theme reads product.metafields.reviews.rating and product.metafields.reviews.rating_count.

App blocks elsewhere

The Main product section and Featured product section support app blocks at the root level. ADLAC also includes generic app-capable wrapper sections/blocks for app content that does not belong inside the product tabs.

Third-party styling can vary.ADLAC provides compatible containers and native theme typography where possible, but the final markup and controls inside an app block are owned by the installed app.
