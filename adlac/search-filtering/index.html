Search & filtering

ADLAC combines predictive search with a full search template that supports products, articles, pages, facets, sorting, and mobile filtering.

ADLAC 1.0.0Shopify Online Store 2.0

Header predictive search

When search is enabled in the Header, ADLAC can render predictive search suggestions. The rotating placeholder labels are configured in the Header section.

Search results

The Search template searches products, articles, and pages. It includes a query form, result count, sorting, desktop filters, active filter chips, a mobile filter drawer, pagination, and an empty state.

Product results

Product results reuse the same product-card component used elsewhere in ADLAC, including optional Quick Buy, swatches, secondary image behavior, image ratio, and image fit.

Facets

The reusable facets UI handles Shopify filter values, price ranges, counts, and Shopify swatch values where available. Configure which filters appear using Shopify's storefront filtering tools.
