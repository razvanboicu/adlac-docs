Setup

Getting started

Configure ADLAC in an order that minimizes rework and makes the storefront easier to test.

ADLAC 1.0.0Shopify Online Store 2.0

Install or add ADLAC to your theme library

Open Online Store → Themes in Shopify Admin, then open ADLAC in the theme editor. Keep an unpublished copy while you configure and test the store.

Configure global Theme settings

Set typography, page width, brand colors, corner radii, Quick Buy media presentation, favicon, and social links before fine-tuning individual sections.

Configure navigation

Assign the main menu, footer menu, customer account menu, and any Mega menu — columns, Mega menu — visual grid, or Compact dropdown blocks that should match top-level menu items.

Prepare product data

Add product media and variants, configure Shopify swatches where needed, set pickup or selling plans when applicable, and create the optional specs.* metafields for technical specifications.

Configure collection and search filters

ADLAC renders Shopify's native collection and search filters. Configure which filters are available in Shopify before testing the storefront.

Add app blocks

Install any required apps, then add compatible app blocks in the Main product section, Featured product section, generic app-capable sections, or inside a product Information tab.

Test before publishing

Test desktop and mobile layouts, keyboard navigation, product variants, cart actions, filtering, search, languages/countries, videos, 3D media, gift cards, and installed app blocks.

Development-safe setup

Keep the theme portable.Store-specific products, collections, uploaded files, app blocks, and demo resources are useful while developing a demo store, but they should not be serialized into the final distributed theme package.

Before you publish

  • Confirm every navigation link and call-to-action has a valid destination.
  • Check collection and product cards with sale, sold-out, multiple-variant, and single-variant products.
  • Test a product with a selling plan, a gift card product, and pickup availability if your store uses those Shopify features.
  • Verify review/app blocks after switching variants and after opening an initially inactive Information tab.
  • Test the storefront in the languages and countries you intend to publish.
