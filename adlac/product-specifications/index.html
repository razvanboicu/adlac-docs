Product specifications

Configure the optional product metafields that power ADLAC's Technical specifications content.

ADLAC 1.0.0Shopify Online Store 2.0
Namespace used by ADLAC: specs. Only metafields that contain a value are rendered; empty values are skipped automatically.

Create metafield definitions

In Shopify Admin, create product metafield definitions for the keys you intend to use. A Single line text field is a practical choice for concise technical values. You can associate definitions with relevant product categories to keep the product editor focused.

Product specifications block settings

The block can show or hide its heading, use Cards or Technical list layout, control desktop/mobile columns, limit the maximum number of specs, show icons, and set the card corner radius.
