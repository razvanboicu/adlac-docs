Store navigation

Header & navigation

Configure the ADLAC header, search experience, announcement bar, mega menus, and compact dropdowns.

ADLAC 1.0.0Shopify Online Store 2.0

Header basics

The Header supports a logo, adjustable logo width, a navigation menu, sticky behavior, storefront search, rotating search placeholder text, header corner radius, and a separate customer account menu.

Menu matching matters.Mega menu and Compact dropdown blocks use the exact title of a top-level menu item. If the title in Navigation changes, update the block's Top-level menu item setting to match.

Mega menu — columns

  • Choose the top-level menu item to enhance.
  • Set the number of menu columns.
  • Add up to two optional promotional products with descriptions.
  • Control promotional image ratio, image corner radius, and whether promotion prices are shown.

Mega menu — visual grid

The visual grid displays child navigation items as visual cards. You can control the desktop columns, frame style, media area size, image spacing, fit, scale, and corner radius. Up to eight custom images can be supplied; when possible, the theme can use imagery associated with linked products or collections.

Compact dropdown

Use Compact dropdown when a top-level item needs a simple menu rather than a large mega menu. The block lets you select a narrow, medium, or wide dropdown width.

Search

The header search can rotate between three merchant-defined placeholder labels at a configurable interval. Predictive search results are rendered by the theme and can surface Shopify search suggestions and resources.

Announcement bar

The announcement bar is part of the header section group. It supports desktop and mobile text, an optional link and arrow, badge text, icon, alignment, width, card presentation, glass styling, and independent colors when theme colors are disabled.
