Header predictive search

Configure the search experience offered from the storefront header.

ADLAC 1.0.0Shopify Online Store 2.0
Where to startOpen Online Store → Themes → Customize and select the relevant template, header/footer group or compatible product block. Use the related schema pages for exact available settings.

Header predictive search

When search is enabled in the Header, ADLAC can render predictive search suggestions. The rotating placeholder labels are configured in the Header section.
